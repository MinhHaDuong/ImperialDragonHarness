## Executed arithmetic source

The following one-off audit generated the numeric table above. It is evidence,
not a reusable numerical helper or new skill implementation. Decimal inputs in
the table are synthetic constants. The binary boundary explicitly converts the
Python binary64 value to its exact decimal expansion.

```python
from decimal import Decimal, ROUND_HALF_UP, localcontext
from pathlib import Path
pairs = [('positive agreement','1.2344','1.2345'), ('positive exact tie','1.234999','1.235'), ('negative exact tie','-1.234999','-1.235'), ('signed zero','0','-0'), ('opposite signs','1.234','-1.234'), ('large carry','999.49','999.5'), ('small carry','0.0099949','0.009995'), ('same rounded across carry','999.5','1000.4'), ('tiny finite','1e-99','1.001e-99'), ('large finite','1e99','1.001e99'), ('binary conversion boundary',str(Decimal.from_float(1.005)),'1.005')]
rows=[]
with localcontext() as ctx:
    ctx.prec=250
    for label,a,b in pairs:
        x,y=Decimal(a),Decimal(b)
        rounded=[]
        for v in (x,y):
            rounded.append(v.quantize(Decimal(1).scaleb(v.adjusted()-2),rounding=ROUND_HALF_UP) if v else Decimal(0))
        rounded=[v.quantize(Decimal(1).scaleb(v.adjusted()-2)) if v else Decimal(0) for v in rounded]
        rows.append(f'| {label} | {a} | {b} | {rounded[0]} | {rounded[1]} | {y-x} | {"agreement" if rounded[0]==rounded[1] else "disagreement"} |')
Path('design/reviews/t1583/arithmetic.md').write_text('''# Exact arithmetic audit

| Control | First original | Second original | First rounded | Second rounded | Original difference | Outcome |

'''+ '\n'.join(rows)+'\n')
```
