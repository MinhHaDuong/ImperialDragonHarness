### D — Bash command denied

Three distinct sub-patterns:

1. **guard-destructive-bash.sh blocking `git clean -fd`** — working as designed;
   agent fell back to safer `git checkout -- .`. No ticket.

2. **rtk proxy rejecting `find … -not -path`** — working as designed (proxy
   rejects compound predicates). Agent recovered with Grep/Glob tools. No ticket.

3. **Orphaned locked worktrees** — killed beat agents leave git-locked worktrees;
   subsequent runs fail `git worktree remove`. Recurring (seen in prior logs too).
   **No existing ticket — new ticket created: 0114.**
