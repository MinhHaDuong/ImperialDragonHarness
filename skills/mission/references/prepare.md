# prepare

The invitation or acceptance is in, the trip is decided. Steps 1-7 run in
order; 3 and 4 stop for the author.

## Registers

- Roadmap: yes, a row in the communications section as the local `AGENTS.md`
  names it: event, date, place, announced title, status "accepted".
- Publications list: no. A talk enters it once given, at the return stage.

## Provenance

The invitation or acceptance mail and the registration receipt, saved as
received (mail as Markdown or `.eml`, receipt as the PDF the organisers sent).

## Filesystem

1. Create the dossier under the active dossiers, named as the local
   `AGENTS.md` says, with a `voyage/` subfolder for the travel order, bookings
   and cancellations, and a README holding a table of subfolders.
2. File the invitation and the registration receipt; one README line each.

## Outward gates (who clicks)

3. Estimate and travel order: the agent prepares the figures (dates, transport,
   nights, registration fee) from the dossier; the author submits the order in
   the institution's system named by the local `AGENTS.md`.
4. Bookings go through the institution's travel procedure named by the local
   `AGENTS.md`, never bought by hand; the author confirms each booking. File
   each confirmation in `voyage/` as it arrives.
5. Registration with the organisers, if not done: the author clicks; the
   receipt is filed.
6. Roadmap row written as the local `AGENTS.md` says.
7. Calendar entry for travel and the slot, once the programme is known.

## Delegates

- `/conference-submission-prep` if an abstract is still owed.
- `/message-framing` to frame the talk early.

## Author-only (ask, do not drop)

- Travel order submitted and signed.
- Visa, insurance, or a mission abroad declared where the institution
  requires it.
- Co-speakers or co-authors told of the trip.

## Done when

The dossier exists with its README and `voyage/`, the travel order is
submitted, bookings and registration are filed, the roadmap row is written,
and every author-only item has an answer.
