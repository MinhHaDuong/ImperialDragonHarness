## Decision Framework

After completing evaluations, rank by:

1. **Must-submit**: Strong fit, achievable deadline, high value
2. **Should-submit**: Good fit, requires some adaptation
3. **Could-submit**: Acceptable fit, backup option
4. **Skip**: Poor fit or impractical constraints

## Timeline Planning

Map deadlines to preparation capacity:

```
[Month 1] ----[Deadline A]----[Deadline B]----
          |                   |
          Prep A starts       Prep B starts (adapt from A)
```

Avoid overlapping intensive preparation periods.

## Red Flags

Skip venues showing:
- CFP language misaligned with project type
- No appropriate format (e.g., only long papers when you have preliminary results)
- Unrealistic timeline given current material state
- Community unlikely to value the contribution type
- Cost disproportionate to strategic value
