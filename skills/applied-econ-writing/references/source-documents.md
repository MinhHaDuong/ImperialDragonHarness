# Source Documents and Additional Resources

## Primary Sources

This skill synthesizes methodologies from:

### Jesse Shapiro – Four Steps to an Applied Micro Paper
- **URL**: https://shapiro.scholars.harvard.edu/sites/g/files/omnuum7731/files/shapiro/files/foursteps.pdf
- **Key contribution**: Four-step process (aspirational intro → research → robot → contractual intro)
- **Research question criteria**: Has answer, not obvious, actionable

### Keith Head – The Introduction Formula
- **URL**: https://blogs.ubc.ca/khead/research/research-advice/formula
- **Key contribution**: Five-component introduction structure (Hook → Question → Antecedents → Value-Added → Road-map)
- **Origin**: Jim Brander via John Ries at UBC

### Marc F. Bellemare – How to Write Applied Papers in Economics
- **URL**: https://marcfbellemare.com/wordpress/wp-content/uploads/2020/09/BellemareHowToPaperSeptember2020.pdf
- **Key contribution**: Complete paper structure, empirical framework, results presentation, journal selection
- **Length**: 42 pages, comprehensive guide

### J-PAL – How to Write a Competitive Grant Proposal
- **URL**: https://www.povertyactionlab.org/sites/default/files/research-resources/J-PAL's%20Guide%20on%20How%20to%20Write%20a%20Competitive%20Proposal%20(document).pdf
- **Key contribution**: Grant proposal methodology, theory of change, power calculations

### Matthew Gentzkow – Lab Manual / Code and Data
- **URL**: https://github.com/gentzkow/lab-manual-archive/wiki <!-- harness-extension-point -->
- **Code and Data guide**: https://web.stanford.edu/~gentzkow/research/CodeAndData.pdf
- **Key contribution**: Research project management, code standards, workflow
