Stopguard design session, 2026-10-21 (session on padme, writer Sonnet 5.5). The author asked whether an end-of-turn hook could keep an agent from stopping on a question it had not asked up, or on a wait nothing would wake. A headless smoke test on all three harnesses (Claude Code 2.1.306, Codex `codex exec`, Pi 1.3.0 `-p`) showed a hook that blocks the first stop and lets the second through makes the agent continue each time. Claude Code needed a local settings file and Codex needed the hook passed inline with `-c`: a project-local `.codex/hooks.json` did not load headless even with the trust bypass. Pi continued through `pi.sendUserMessage(..., {deliverAs: "followUp"})`; returning `continue: true` alone failed with "requested continuation without runnable model context".

PR #1545 merged the design (`docs/2026-10-21-stopguard-design.md`) and the deferred tracker `tickets/1164-stopguard-end-of-turn-hook-tracker.erg`. Nothing is implemented. The author decided: dry-run first; a local untracked spool with a weekly report and a labeled set tracked in the repo, rather than a live tracked log (a hook appending to a tracked file dirties main and runs in every project); no implementation and no phase 0 on the day. A second session forked from this one designed the waiter for the second stop pattern; both agreed that this hook is the only Stop-hook implementation and the waiter owns the wait registry.

Review trail: Fable (Agent token `fable`) returned APPROVE WITH FIXES with 12 findings, one blocking and verified (the planned `telemetry/` path is ignored by `.gitignore`, which allows only listed roots). Astra (`codex exec -m gpt-6-astra`, reasoning effort high, session header `model: gpt-6-astra`) returned REWORK with 11 findings, two blocking. A Sonnet KISS pass cut enforcement, markers, four measures and the per-harness replay from the first release. The design was rewritten twice; the second rewrite is the merged version. The final text was not reviewed again after the fixes.

Author feedback during the session: the first draft described Pi's adapter as a caveat and offered a Claude Code and Codex only scope, which the author rejected as treating Pi as second class; later the author rejected both a "re-run roar later" hand-off and a fixed 15-minute wake-up timer ("I AM NOT YOUR WAITER"). The accepted form was one background command with a hard timeout that exits on the event. Feedback memories were written for both.
