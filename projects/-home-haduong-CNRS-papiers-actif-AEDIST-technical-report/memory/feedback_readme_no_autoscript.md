When a README needs to be written or substantially improved for an experiment output folder, write it directly — do not propose or create a Python script to generate it.

**Why:** User explicitly rejected a planned `exp2_phase_b_full_readme.py` script: "No script, you do it by hand now." The user wants the README to be a deliberate, readable artifact, not auto-generated output.

**How to apply:** For output folder READMEs (like `sota_exp2_phase_b_full/README.md`), read `summary.json` and flat `agent_runNN.json` files yourself, then write the README directly with the Edit/Write tool. The naive arm README (`sota_exp2_naive_arm/README.md`) is the quality reference.
