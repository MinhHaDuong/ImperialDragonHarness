Minh Ha-Duong is an École Polytechnique alumnus, promotion 1988 (X88).

When drafting correspondence to another Polytechnique alumnus/alumna on his
behalf, use the "camarade" convention:

- Open with "Cher Camarade" / "Chère Camarade" rather than a generic
  professional salutation.
- Tutoiement ("tu") only if the promotion gap is under 10 years
  (|their class year − 1988| < 10); otherwise "vous", even while still
  using "Camarade".

Example: Claire Gavard is X2008 — gap of 20 years, so "Chère Camarade" +
"vous", not "tu" (established in the Gavard–Schoch correspondence,
2026-09-11, see [[reference_gavard_schoch_correspondence]]).

This applies whenever drafting a message to a known Polytechnique alumnus,
in any project — not specific to one correspondence thread.
