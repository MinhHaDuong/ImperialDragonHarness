# Memory index — Oeconomia « Le cœur absent » (production jointe / IAM)

## Key insights

- Vérifier le CONTENU à la source primaire avant d'écrire, pas seulement l'existence de la référence — trois preuves cette semaine : Simon 1978 (fausse citation évitée), Nordhaus 1979 ch. 2 (attribution de PM réfutée sur le scan Cowles), six erreurs de biblio débusquées par la passe prénoms complets.
- Fichier daté figé dès envoi ; toute édition nouvelle ouvre le fichier du jour ; une correction post-gel se fait par dé-gel documenté + re-gel, jamais en silence.
- La chirurgie XML des ODT est fiable en tout-ou-rien : aiguilles vérifiées uniques (grep/repr d'abord — apostrophes, NBSP, spans), assert count==1, minidom avant écriture.
- Le standard HPE (flèche pleine = auto-attestation par le texte cible) et le patron un-agent-par-item se réutilisent bien : 13 flèches de la figure, 81 prénoms de biblio, 62 cibles de moisson — toujours avec vérification indépendante des retours d'agents.
- La devise de Minh — intégrité, excellence, bienveillance — tranche les arbitrages pratiques ; application fondatrice : un champ contient ce que son nom dit (abstract = abstract).
