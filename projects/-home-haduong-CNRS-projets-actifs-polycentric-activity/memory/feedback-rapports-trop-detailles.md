Rapports trop longs. « Beaucoup trop détaillé ! » (2026-08-17). Réduire le fil à
la conclusion, la décision demandée, et où lire le reste.

**Why:** le dossier Cournot a produit des rapports de trente lignes avec
tableaux, alors que le détail était déjà dans la note `conception/` et dans le
ticket, tous deux liés. Le fil répétait un livrable qui existait ailleurs. Le
temps de l'auteur est la ressource rare, et un rapport qu'il faut parcourir pour
trouver la question est un coût qu'il paie deux fois.

**How to apply:** trois lignes par défaut. Ce qui est fait, où c'est, ce qu'on
attend de lui. Pas de tableau récapitulatif quand la note en porte un. Pas de
citation verbatim dans le fil quand elle est dans le dossier. Le détail se met
dans l'artefact, pas dans la conversation — et l'artefact est déjà écrit, donc le
répéter n'ajoute rien. Voir [[feedback-no-inverted-centaur]] : lui épargner du
travail vaut aussi pour la lecture.
