When the user shares a conference or journal URL, fetch and read the actual page before offering opinions or strategic advice.

**Why:** In this session, initial advice was wrong on multiple points (conference dates, paper length, OA status) because it was based on assumptions rather than the actual website content. The user had to prompt "Reviewed the conference and journal homepages?"

**How to apply:** Any time the user provides URLs for venues, conferences, or journals, WebFetch them immediately before commenting on strategy, format, or deadlines.
