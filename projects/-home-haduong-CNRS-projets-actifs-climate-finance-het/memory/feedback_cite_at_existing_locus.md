When a referee asks to add a reference, read it in full, then find where the
manuscript **already** states the point and where the reference carries a load
no adjacent citation already carries. The integration is usually posing a
citation at an existing locus, not writing new content.

**Why:** two 0143 (#916) integrations both turned on this.
- **Golka (R1.1):** §165 already wrote "productive circularity" — R1's own
  phrase for the mechanism. Integration = one citation at that sentence, framed
  as a parallel case (Golka's object is private finance, not the ODA apparatus,
  so "a comparable dynamic", not attribution).
- **Escobar (R2.30):** the obvious locus (§98, biased-aid-architectures) already
  had Mitchell 2002 doing the apparatus-as-technical critique. Escobar's
  *distinct* load is the visibility thesis of *Power and Visibility*, which is
  the manuscript's own recurring figure (§161 "visible / invisible"). Placing it
  there is non-redundant; doubling Mitchell at §98 would be padding.

**How to apply:** (1) read the source fully — [[reference_read_before_cite]] /
[[feedback_read_before_cite]]. (2) grep the manuscript for the concept/phrase
the referee invokes; the referee often points at a passage that already argues
it. (3) ask what load this reference carries that adjacent citations do not — if
none, it is padding; decline or find its distinctive locus. (4) frame with an
honest verb when the source's claim is stronger or in an adjacent domain
("Escobar traced the same power in the postwar development apparatus", not
endorsement of his totalizing anti-development thesis). Related:
[[feedback_atomic_tickets_validation_units]].
