## Key insights

- Agent scope drift is the dominant failure mode: verify agents spiral, parallel agents contaminate branches, forks start bare and under-execute, and every agent-execution surface (Workflow, context:fork, Agent) has its own isolation + cwd-binding defaults — know them before launch. Defense: explicit "task complete after verdict", worktree isolation on mutating call sites, imperative TASK DIRECTIVE openers, post-agent git status checks (re-confirmed 2026-06-06: a gaze fork left the session checkout on the PR branch — benign, re-switch; structural fix ticketed 0228).
- Write-commit atomicity is a hard constraint imposed by beat's dirty-tree gate. Any skill writing tracked files without an immediate commit blocks the next beat cycle — and new files under the IDH gitignore whitelist are invisible to plain status/add (need add -f), so a session can commit an index line while orphaning the entry file. The housekeeping sweep adopts such orphans; the discipline is commit-with-write, every time.
- Fidelity checks pass what runtime breaks: extraction, adherence tests, and gaze verify that code matches its spec, not that it works. The 2026-06-06 post-merge high-effort review of a gaze-APPROVED PR found three confirmed runtime defects (basename/path key mismatch silently killing three features; schema-valid-but-empty inputs bypassing every gate). Probe runtime cheaply before expensive fan-outs; review post-merge when the gate ran degraded; make every ratchet prove RED on the pre-fix state.
- Security architecture is first-class and needs an explicit path BEFORE implementation, on two axes: the credential path (BASH_ENV→bash-env.sh vs argv-leak; subscription auth vs funded direct-API key) and containment (real isolation is OS-level — seccomp / bubblewrap / rootless podman — never a cooperative protocol grant or an agent "mode", which a misbehaving or injected process bypasses).
- This memory is the harness's operational runbook: invisible invariants and failure modes discovered at cost, not what the code does (that's git) nor architecture decisions (those live in tickets and docs/). Value compounds across sessions.
