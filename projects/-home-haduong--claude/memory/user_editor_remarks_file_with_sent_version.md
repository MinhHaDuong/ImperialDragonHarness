When an editorial decision or referee reports arrive (days/weeks/months after
submission), file them **with the version that was sent** — retroactively, in
that submission's `sent/` folder (`~/CNRS/papiers/sent/<paper>/` for manuscripts;
the corresponding `~/CNRS/missions/` sent location for slide decks) — **not**
with the new active working directory under `~/CNRS/.../actifs/` where the
revision is being worked on. The remarks judged the sent version, so they belong
beside it.

Filing lifecycle: work lives in `actifs/`; **on submission** the folder moves to
`sent/`; the decision lands later and joins it there.

This is a fact to apply with judgment, deliberately **not** a hard harness rule —
see [[feedback_dont_codify_hard_rules]]. (From the IDH 0264 discussion,
2026-07-10.)
